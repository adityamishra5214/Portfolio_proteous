# Portfolio Assets

Place real portfolio files in these folders:

- `brand-logos/` - one logo per portfolio brand
- `brand-images/` - primary brand or company imagery
- `founders/` - founder and co-founder portraits
- `reference/` - PDFs, source documents, or visual references

Recommended naming pattern:

- `brand-01-logo.png`
- `brand-01-image.jpg`
- `brand-01-founder-01.jpg`
- `brand-01-founder-02.jpg`

The current portfolio still uses placeholder content until the real files and information are supplied.
